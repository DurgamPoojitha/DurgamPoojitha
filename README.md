> **The problem it solves:** SQL injection attacks use obfuscation (Base64, hex encoding, nested functions) to bypass simple rule filters. This hybrid system catches both pattern-level and semantic-level attacks.

**Architecture:** Hybrid detection combining hand-engineered rule-based feature extraction (SQL keyword patterns, encoding detection, obfuscation analysis) with a Logistic Regression classifier. Evaluation pipeline includes ROC/PR curve analysis and automated HTML report generation.

**Tech Stack:** `Python` · `Scikit-learn` · `Feature Engineering` · `ML` · `Security Analysis`

**Engineering highlights:**
- ✅ Multi-layer detection: keyword patterns + encoding layers + Base64/hex obfuscation decoding
- ✅ ROC/PR analysis pipeline with high-precision attack detection metrics
- ✅ Automated HTML security report generation for model performance visualization
- ✅ Hybrid architecture outperforms pure ML or pure rule-based approaches in adversarial scenarios

**Why recruiters notice this:** Security + ML cross-domain thinking. Demonstrates adversarial problem modeling, hybrid system design, and engineering rigor in evaluation.
